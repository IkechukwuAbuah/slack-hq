# Claude Artifacts

This directory stores documents and logs generated by Claude Code during development workflows. Unlike ChatGPT artifacts (typically DOCX), Claude primarily generates markdown and text-based outputs.

## Purpose

Claude Code generates:
- **Markdown** - Documentation, specs, and analysis outputs
- **Text logs** - Session tracking data, command outputs
- **Code snippets** - Temporary code generation for comparison
- **Analysis reports** - Codebase analysis, security audits

These artifacts are typically temporary working copies or logs, not final deliverables.

## Typical Workflow

### 1. Generation Phase (Claude)
```
Claude Code → Generates markdown analysis
Claude → Saves to artifacts/claude/analysis-2025-11-03.md
```

### 2. Review Phase
```bash
# Review generated content
cat artifacts/claude/analysis-2025-11-03.md

# Compare with existing documentation
diff docs/specs/feature.md artifacts/claude/analysis-2025-11-03.md
```

### 3. Integration Phase
```bash
# If analysis is valuable, integrate into /docs
# Either merge manually or replace existing doc

# Move to appropriate location
mv artifacts/claude/analysis-2025-11-03.md docs/specs/feature-analysis.md
```

### 4. Cleanup Phase
```bash
# Remove artifact if no longer needed
rm artifacts/claude/analysis-2025-11-03.md
```

## Supported Formats

### Markdown (.md)
**Use for:**
- Codebase analysis outputs
- Documentation drafts
- Comparison versions of existing docs
- Experimental documentation structures

**When to keep:**
- Provides valuable comparison with source
- Contains analysis not yet integrated
- Reference for iterative improvements

**When to delete:**
- Content merged into `/docs`
- Analysis complete and no longer needed
- More than 7 days old with no references

### Text Logs (.txt)
**Use for:**
- Session tracking logs
- Command execution transcripts
- Debug output captures
- Tool execution summaries

**Example:**
```bash
# Session log from session tracking
artifacts/claude/session-a1b2c3d4.txt

# Command execution log
artifacts/claude/build-output-2025-11-03.txt

# Debug trace
artifacts/claude/debug-trace-auth-issue.txt
```

### JSON Data (.json)
**Use for:**
- Structured session data
- API response captures
- Configuration snapshots
- Test data samples

**Note:** Session tracking JSON is stored in `.claude/data/sessions/`, not here.

## Session Tracking Integration

Claude's session tracking system generates artifacts:

```
.claude/data/sessions/          # Primary storage (gitignored)
├── a1b2c3d4-5e6f-7890.json    # Session metadata
└── ...

artifacts/claude/               # Optional logs (gitignored)
└── session-a1b2c3d4.txt       # Human-readable log
```

**Workflow:**
```bash
# Start session (creates .claude/data/sessions/*.json)
/session-start "Implement feature X"

# Work proceeds, activities logged
# ...

# Generate human-readable summary (optional)
/session-stop --notes "Completed implementation"

# Optional: Export session log to artifacts for reference
cp .claude/data/sessions/a1b2c3d4*.json artifacts/claude/session-a1b2c3d4.json
```

**Scenario:** Claude generates updated version of existing doc

```bash
# Claude generates updated version

# Compare versions
diff docs/specs/authentication.md artifacts/claude/authentication-v2.md

rm artifacts/claude/authentication-v2.md
```

### Use Case: Analysis Reports

**Scenario:** Claude analyzes codebase and generates report

```bash
# Claude analyzes codebase
# Generates: artifacts/claude/security-audit-2025-11-03.md

# Review findings
cat artifacts/claude/security-audit-2025-11-03.md

# Create action items from findings
# (Linear issues, ADRs, etc.)

# Or move to docs/reports/ if valuable long-term
```

## Naming Conventions

Use descriptive names with context and dates:

```
# Good names
analysis-auth-module-2025-11-03.md
session-log-feature-impl-20251103.txt
security-audit-api-20251103.md
performance-report-2025-11-03.md

# Bad names
output.md
log.txt
document.md
file1.txt
```

**Pattern:** `<purpose>-<context>-<date>.md`

## Integration with ChatGPT Artifacts

### Handoff Pattern: Claude → ChatGPT

```bash
# Claude generates markdown analysis
artifacts/claude/feature-requirements.md

# If formal document needed for stakeholders:
# 1. Refine in markdown (Claude)
# 2. Move to /docs
# 3. Generate DOCX for stakeholders (ChatGPT or convert.sh)
```

### Handoff Pattern: ChatGPT → Claude

```bash
# ChatGPT generates DOCX
artifacts/chatgpt/initial-spec.docx

# Convert to markdown
./scripts/convert.sh docx2md artifacts/chatgpt/initial-spec.docx

# Claude refines markdown
artifacts/claude/initial-spec-refined.md

# Finalize in /docs
mv artifacts/claude/initial-spec-refined.md docs/specs/feature-spec.md
```

## Retention Policy

### Keep When:
- Active work in progress (< 7 days)
- Reference for ongoing comparison
- Contains unique analysis not elsewhere
- Part of iterative refinement workflow

### Delete When:
- Content integrated into `/docs`
- Analysis complete and documented
- Session work concluded
- More than 30 days old with no activity

### Cleanup Commands
```bash
# List old Claude artifacts
find artifacts/claude/ -type f -mtime +30 ! -name "README.md" ! -name ".gitkeep"

# Delete old artifacts
find artifacts/claude/ -type f -mtime +30 ! -name "README.md" ! -name ".gitkeep" -delete

# Archive session logs before deletion
tar -czf session-logs-archive-$(date +%Y%m%d).tar.gz artifacts/claude/session-*.txt
```

## Best Practices

### 1. Temporary by Default
Claude artifacts are working files, not final deliverables:
```bash
# Generate analysis
artifacts/claude/analysis.md

# Review and integrate
# (Merge into docs/specs/feature.md)

# Delete artifact
rm artifacts/claude/analysis.md
```

### 2. Session Logs
Keep session logs only when valuable for reference:
```bash
# Auto-generated during session
# .claude/data/sessions/abc123.json

# Optional: Export for reference
cp .claude/data/sessions/abc123.json artifacts/claude/session-abc123.json

# Delete after 30 days
```

### 3. Comparison Versions
Use for iterative improvements:
```bash
# Original
docs/specs/feature.md

# Claude's improvements
artifacts/claude/feature-v2.md

# Compare and merge
diff docs/specs/feature.md artifacts/claude/feature-v2.md

# Update original
# (Selective merge of improvements)

# Delete comparison version
rm artifacts/claude/feature-v2.md
```

### 4. Analysis Reports
Archive valuable analyses:
```bash
# Claude generates security audit
artifacts/claude/security-audit-2025-11-03.md

# If valuable long-term, move to /docs
mv artifacts/claude/security-audit-2025-11-03.md docs/reports/security/audit-2025-11-03.md

# Or delete if ephemeral
rm artifacts/claude/security-audit-2025-11-03.md
```

## Common Patterns

### Pattern 1: Iterative Refinement
```
docs/specs/feature.md (v1)
→ Claude analyzes and improves
→ artifacts/claude/feature-v2.md
→ Compare and merge improvements
→ docs/specs/feature.md (v2, enhanced)
```

### Pattern 2: Session Logging

```
→ .claude/data/sessions/abc123.json created
→ /session-stop

```

### Pattern 3: Codebase Analysis
```
Claude analyzes codebase
→ artifacts/claude/analysis-2025-11-03.md generated
→ Review findings
→ Create action items (Linear, ADRs)
→ Delete artifact after actions created
```

## Quality Checks

Before deleting Claude artifacts, ensure:

- [ ] All valuable content integrated into `/docs`
- [ ] Analysis findings converted to action items
- [ ] Session data preserved if needed for audit trail
- [ ] No unique insights lost
- [ ] Comparison work complete

## Troubleshooting

### Issue: Need to recover deleted artifact
**Solution:** Check git history if accidentally committed
```bash
git log --all --full-history -- artifacts/claude/lost-file.md
git show <commit>:artifacts/claude/lost-file.md
```

### Issue: Too many artifacts accumulating
**Solution:** Implement regular cleanup schedule
```bash
# Weekly cleanup (add to cron or run manually)
find artifacts/claude/ -type f -mtime +7 ! -name "README.md" -delete
```

### Issue: Session log too large
**Solution:** Compress or split large logs
```bash
# Compress large session log
gzip artifacts/claude/session-large.txt

# Or split into chunks
split -l 1000 artifacts/claude/session-large.txt artifacts/claude/session-part-
```
